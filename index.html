KT 인터넷·TV 쿠폰(선납권) 등록관리

로우데이터 업로드 → 대상 추출/검증 → 다우오피스 · KT전산 등록용 파일 생성

1. 로우데이터 업로드

원본 파일(.xls / .xlsx / .csv)을 드래그하거나 클릭해서 선택하세요.

2. 추출 결과 요약

• 오류 표시된 건은 다운로드 엑셀에도 포함되지만(보정값 기준), 표에서 셀을 직접 눌러 수정한 뒤 다시 다운로드하세요.
• 금액: 9·10개월로 나눠 1,000원 단위로 떨어지면 정상(부가세 10% 반영), 1,100원 단위로만 떨어지면 "부가세포함 입력오류"(원본값 그대로 사용), 둘 다 안 맞으면 "나눗셈불가오류"(수기확인).
• TV 서비스계약번호(SAID)는 로우데이터에 거의 입력되어 있지 않아 KT전산에서 직접 확인 후 수기 입력해야 하는 경우가 많습니다.

3. 등록 대상 목록 (그룹: 고객명+유치자 기준)

No 확인 고객명 유치자 협력점/부서 개통일 상품구성 원본금액 산출(부가세포함)/개월 총금액 인터넷 SAID TV SAID 오류

4. 파일 다운로드

• 다우오피스 파일은 비용분담(우신기술사업부 vs 그 외 전체) 때문에 2개로 분리해서 내려받습니다.
• KT전산 등록은 월 쿠폰금액을 1순위로 TV에 전액(최대 11,000원) 반영하고, 초과분만 인터넷 파일에 담습니다. 초과 건이 없으면 인터넷 파일은 0건일 수 있습니다.
• 할인시작 월은 파일 생성일 기준 다음달로 자동 계산됩니다.
